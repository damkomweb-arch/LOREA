# LOREA Website

Static bilingual website for **LOREA — Made to Be Remembered**.

## Brand system
- Ivory `#F8F5F0`
- Sage `#A8B5A2`
- Champagne `#D8C3A5`
- Charcoal `#2F2F2F`
- Display: Cormorant Garamond
- Body: Manrope

## Features
- Responsive mobile-first layout
- English / Arabic toggle with RTL support
- Signature product storytelling
- Cake flavor and gift customization form
- Ready-to-send WhatsApp order message
- Lightweight static deployment (GitHub Pages compatible)

## Deployment
Publish the repository root from the `main` branch with GitHub Pages.
